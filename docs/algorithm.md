# Блок-схема основного алгоритма

Ищем положительные чётные делители введённого целого числа. Обозначения: `n` — введённое число, `m` — его модуль, `d_min` и `d_max` — минимальный и максимальный чётные делители.

```mermaid
flowchart TD
    start(["Начало"]) --> input[/"Ввод числа n"/]
    input --> integer{"Введено целое число?"}

    integer -- "Нет" --> inputError[/"Вывод сообщения:<br/>требуется целое число"/]
    integer -- "Да" --> zero{"n = 0?"}

    zero -- "Да" --> zeroError[/"Вывод сообщения:<br/>у нуля нет максимального<br/>положительного чётного делителя"/]
    zero -- "Нет" --> absolute["m ← |n|"]
    absolute --> even{"m кратно 2?"}

    even -- "Нет" --> none[/"Вывод сообщения:<br/>чётных делителей нет"/]
    even -- "Да" --> calculate["d_min ← 2<br/>d_max ← m"]
    calculate --> output[/"Вывод минимального делителя d_min<br/>и максимального делителя d_max"/]

    inputError --> finish(["Конец"])
    zeroError --> finish
    none --> finish
    output --> finish
```
