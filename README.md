# Задача № 6: чётные делители

Учебное приложение на SvelteKit, Svelte 5 и TypeScript: запросить целое число и вывести его максимальный и минимальный чётные делители. Одна страница, вычисления выполняются в браузере.

## Условие и допустимый ввод

Ищем **положительные чётные делители**. Для отрицательного числа используем его модуль.

Принимается десятичная запись целого числа с необязательным знаком `+` или `-`. Пробелы по краям удаляются, ведущие нули допустимы. Вся строка проверяется до преобразования; дроби, экспоненциальная и шестнадцатеричная записи недопустимы.

Диапазон: от `-9007199254740991` до `9007199254740991`. После преобразования проверяется `Number.isSafeInteger`: значения за границами отклоняются, точность не теряется молча. Ноль, включая `-0`, считается ошибкой: его положительные чётные делители не ограничены сверху.

## Алгоритм

После валидации вычисляется `m = Math.abs(n)`. Если `m` нечётное, чётных делителей нет. Иначе минимум равен `2`, максимум — `m`: `2` — наименьшее положительное чётное число, а положительный делитель ненулевого числа не превосходит его модуль. Перебор не нужен.

Вычисление занимает `O(1)` времени и памяти; проверка и преобразование строки зависят от её длины. Ошибка ввода, отсутствие делителей и успешный расчёт представлены разными вариантами типизированного результата.

| Ввод                           | Результат                                        |
| ------------------------------ | ------------------------------------------------ |
| `2`, `-2`                      | Минимальный `2`, максимальный `2`                |
| `12`, `-12`, `  +12  `, `0012` | Минимальный `2`, максимальный `12`               |
| `7`                            | Чётных делителей нет                             |
| `0`, `-0`                      | Ошибка: максимального делителя нет               |
| `12abc`, `12.0`, `1e3`, `0x10` | Ошибка записи числа                              |
| `9007199254740990`             | Минимальный `2`, максимальный `9007199254740990` |
| `9007199254740991`             | Чётных делителей нет                             |
| `9007199254740992`             | Ошибка безопасного диапазона                     |

## Запуск

Требуются Node.js **22.17 или новее** и npm. Версии зависимостей зафиксированы в `package-lock.json`.

```sh
npm ci
npm run dev
```

Откройте адрес из вывода Vite, обычно <http://localhost:5173>. Форма отправляется кнопкой «Вычислить» или Enter. Изменение ввода сбрасывает прежние результат и ошибку. Без JavaScript доступно условие, но вычисление требует JavaScript.

## Проверки

```sh
npm run check
npm test
npm run lint
npm run build
```

`check` проверяет Svelte и TypeScript; `test` запускает Vitest без watch; `lint` проверяет форматирование и ESLint. Команда `npm run format` форматирует проект, исключая агентное окружение.

Для браузерных проверок один раз установите Chromium:

```sh
npm exec playwright install chromium
npm run test:e2e
```

`test:e2e` собирает приложение и запускает Playwright на локальном preview-сервере `127.0.0.1:4173`; порт должен быть свободен. Проверяются кнопка и Enter, порядок фокуса, ошибки и их исправление, сброс устаревшего результата, отсутствие горизонтального переполнения на ширине 320 px и доступность через axe. Автоматическая проверка не означает полного аудита WCAG.

## Сборка и структура

`npm run build` создаёт статический сайт в `build/` через `adapter-static`, с предварительным рендерингом HTML. SSR не отключён. Проверить сборку локально можно командой `npm run preview`. Автоматическая публикация не настроена.

- `src/routes/+page.svelte` — форма и отображение результата.
- `src/lib/even-divisors.ts` — чистая функция валидации и вычисления.
- `src/lib/even-divisors.test.ts` — обязательные примеры и границы ввода.
- `tests/even-divisors.spec.ts` — браузерные сценарии и axe.

Структура следует `AGENTS.md`: без API, базы данных, глобальных stores и дополнительных архитектурных слоёв. `.gitignore` исключает зависимости, сборку, отчёты, журналы, локальный кэш и `.env*`, сохраняя возможность добавить `.env.example`; lock-файл остаётся в Git.
